# Pinterest play (draft + execute)

Type: task
Status: resolved
Blocked by: 02, 03, 04

## Question

Produce and execute the **Pinterest play**, following the playbook unit (ticket 03), the audience map (ticket 02), and using the pin images from the asset kit (ticket 04).

Agent creates everything:

- Which board(s) to create on the owner's Pinterest, board names/descriptions, and the search terms/keywords to target.
- For each pin image: the pin title + description (keyword-aware, in the owner's voice) and the destination URL (the matching long-tail page, with UTM tags per the measurement decision in ticket 03).
- A posting order/cadence for the first pass (Pinterest rewards steady pinning, not a one-time dump).

The **owner posts** the pins under their own Pinterest account. Record what was pinned + destination URLs for the wrap ticket (10).

## Answer

Drafted at [sites/runs-on-your-battery-finder/distribution/06-pinterest-play.md](../../../sites/runs-on-your-battery-finder/distribution/06-pinterest-play.md),
using the 10 real pin images from the asset kit (ticket 04) and the audience map's Pinterest findings
(ticket 02).

**Boards:** 5, one per platform (DeWalt 20V MAX, Ryobi 18V ONE+, Milwaukee M18, Makita 18V LXT, HART
20V) — grouping by platform fits the pins on hand better than a category split, which would leave
several boards with only one pin. Each board has a description and a target-keyword list.

**Pins:** all 10 asset-kit images given a title (from the pin's headline), a keyword-aware description
in the owner's voice (verified fact first, link second), and a destination URL. Per the playbook's
measurement convention (ticket 03), Pinterest tolerates a tagged link, so every destination carries
`utm_source=pinterest&utm_medium=referral&utm_campaign=distribution-v1` — plus a per-pin `utm_content`
(a small addition beyond the base convention) so the wrap-up (ticket 10) can attribute a referral to the
specific pin/board that drove it, not just "Pinterest" generically.

**Cadence:** boards created on day 1; the 10 pins spaced roughly every 2 days across ~3 weeks, rotating
platforms so no board gets two pins back-to-back — Pinterest rewards a steady drip over a one-time dump.
Repeat rhythm after the first pass stays fog (map's "Not yet specified") until results are in.

The **owner** creates the boards and posts every pin under their own Pinterest account; the agent
drafted everything else. Posting checklist included in the site-specific file. Feeds ticket 10 once
posted.
