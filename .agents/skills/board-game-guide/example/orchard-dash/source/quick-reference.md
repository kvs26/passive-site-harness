# Quick reference

## Rules at a glance

| Item | Rule |
| --- | --- |
| Goal | First to 10 apples |
| Turn | Roll, move, take apples |
| Dashed tree | +1 bonus apple |
| Players | 2-4 |

## Glossary

- **Basket:** where you keep your apples.
- **Dashed tree:** a tree that gives one bonus apple.
- **Pawn:** the piece that shows where you stand.
