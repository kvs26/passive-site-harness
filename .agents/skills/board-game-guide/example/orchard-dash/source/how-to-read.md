# How to read this guide

> **FIXTURE ONLY.** *Orchard Dash* is an invented game used to test the guide builder. It is not a real product and nothing here was researched.

This guide has four tiers. Each one stands on its own, so you can start where you are.

- **Tier 1: How to play** teaches the rules, with one worked example.
- **Tier 2: Beginner tactics** helps you avoid the mistakes most new players make.
- **Tier 3: Intermediate tactics** helps you plan a whole game.
- **Tier 4: Advanced tactics** covers reading opponents and hard choices.

Every tactic uses the same five parts: why it works, when it applies, when it fails, an example, and a common mistake with a fix. Some tactics come from our own analysis of the rules, so treat them as good ideas to try, not laws.

Rules are defined once, in the [quick reference](#quick-reference). Other sections link to it instead of repeating it.
