# Niche: home-appliance-lookup

Per-model/per-unit lookup and decision tools for US household appliances (washers, dryers, refrigerators, dishwashers): compatibility, capacity, dimensions, identification.

**Why this niche:** demand is per-model long-tail (millions of model numbers), which is structurally hard for a single incumbent page to pre-serve — the failure mode that killed prior niches (gate 4, hook already served) is less likely per-query here. Incumbent SERPs are PDF manuals, ad-stuffed repair blogs, and seller tools with conflicts of interest.

**Target market:** US (default).

**Seeds:** washer error code · dryer error code · refrigerator water filter compatible · dishwasher not draining · appliance model number lookup · washer capacity cu ft
