# AI Employee Bundle Catalog

Status: rejected
Origin: ../../runs/2026-08-25-scout.md

## Idea

A curated catalog of role-based agent-skill bundles — "AI marketing assistant", "AI QA engineer", "AI bookkeeper" — each a vetted set of open-source skills + config + plain-English install steps, presented per job function rather than per tool. (Passive-site framing of the user's original "AI Employee" product idea; potential storefront for a paid bundle later.)

## Hook

Every existing directory indexes individual skills for developers; nobody packages them as complete per-role setups a semi-technical operator can install in one sitting.

## Gate results

1. Answer-it test — pass: assembling a working multi-skill role bundle requires curation + compatibility testing, not a one-shot answer.
2. Static feasibility — pass: catalog pages linking to GitHub sources; no backend.
3. Unmaintainable data — pass with note: bundles need re-verification as tools churn; quarterly plausible.
4. No specific hook — **near-miss (why marked weak)**: analoghq.ai already does "share your AI setup as an installable set — skills, MCP servers, plugins" (found via Bing this run); differs by being community-share vs curated-role, but it's close. Also "agent zero skills pack" autocomplete suggests pack-phrasing exists.
5. Legal/policy risk — pass: links to open-source skills; no advice territory.
6. US-market mismatch — pass.
