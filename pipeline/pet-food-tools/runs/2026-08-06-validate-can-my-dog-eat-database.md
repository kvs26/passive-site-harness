# Validate run — 2026-08-06 — can-my-dog-eat-database (pet-food-tools)

## Setup

Credential-free run. Reused scout helper scripts. DDG HTML endpoint (pain-fetch adapter) bot-challenged from the first query — permanent dead end this run; all SERP/pain searches moved to the integrated browser on duckduckgo.com, which worked throughout.

## What was dug, per signal

1. **Demand** — fresh fan-out on 6 seeds (fanout.py, US locale): confirmed long "can dogs eat X" tail plus quantity-shaped panic queries ("dog ate grapes and is fine", "how much chocolate is toxic to dogs"). Pain dig re-verified the two scout Reddit quotes (silica gel 194h1eu, grapes orevs3) live and surfaced two new independent panic threads (chocolate bar 13q5q8y, mushroom 1ddrx8l). Graded strong.
2. **SERP weakness** — 3 SERPs fetched (grapes head term, listicle query, tool query). Head terms: static articles from high-authority sites. Tool query surfaced **two existing interactive competitors** the scout run missed: dogtoxic.com (75 foods) and canmydogeat.org. Both flat-verdict, no quantity/size input. Graded weak (authority head terms + interactive incumbents exist, though thin).
3. **Hook depth** — targeted search for quantity × weight demand: vet-staff LPT recommending chocolate toxicity calculators, "depends on the size of the dog and how much" (r/Pets), a dedicated "chocolate meter" share thread. Hook is user-demanded, not our invention. Graded strong.
4. **Monetization** — inspected caninebible.com grape page: Chewy affiliate banners, pet-insurance, vet-telehealth, Embark, Amazon Associates. dogtoxic.com serves ads on the identical interactive format. Graded strong.
5. **Feasibility** — Merck Vet Manual Food Hazards fetched (updated May 2026), gives explicit per-body-weight dose thresholds free. ASPCA people-foods page unfetchable (ad-tracker redirect) — noted, Merck substitutes. dogtoxic proves the static build. Graded strong.
6. **Unique data** — dose-per-weight structure derivable from Merck; confirmed neither interactive competitor has quantity context. Graded strong.

## Dead ends

- DDG HTML + lite endpoints: bot challenge (consistent with scout run).
- aspca.org people-foods page: redirect to adsrvr.org tracker.
- merckvetmanual.com/toxicology/food-hazards/food-hazards-in-animals: 404 (pet-owner URL is /special-pet-topics/poisoning/food-hazards).

## Notable finding vs. scout

Scout's gate-4 note "no interactive lookup in top SERP" holds for head terms but is false for the space overall — dogtoxic.com and canmydogeat.org exist. Idea survives because the hook (quantity × dog size) is absent from both and strongly evidenced as the thing users actually need.
