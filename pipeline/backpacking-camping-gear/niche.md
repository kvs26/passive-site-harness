# Niche: backpacking & camping gear (interactive planning tools)

Target market: US (default).

## Rationale

Chosen 2026-10-09. User brief: third site should be an interactive, high-utility tool (user inputs -> computed output), more complex than the two data-presentation sites already built. Generic formula calculators (fuel, water, sleep, food weight, pack weight) are saturated by programmatic calculator farms, so the only survivable shapes pair per-query multi-input compute with a hand-verified real-world dataset (regulations, real SKUs).

## Seeds

1. bear canister required
2. bear canister size / how many days of food
3. backpack size for torso length
4. backpacking food planner
5. sleeping bag / pad warmth
6. backpacking stove fuel calculator

Active, first scout run 2026-10-09.
