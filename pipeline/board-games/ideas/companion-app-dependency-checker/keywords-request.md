# Keyword Planner request — companion-app-dependency-checker

Run "Get search volume and forecasts" on these in Keyword Planner (US), download the
historical-metrics export, save as `keyword-planner.csv` in this folder.

## Head

- board game companion app
- board game companion apps
- companion app board game

## Variants (mandatory/optional phrasing)

- is the companion app required to play
- can you play without the app board game
- board game app not working
- board game without the app

## Hook-specific (per-game, from the bounded digital-hybrid list)

- mansions of madness app required
- mansions of madness without the app
- xcom board game without app
- chronicles of crime app required offline
- district noir app
- space cadets board game app

## Future-proofing / support-status phrasing (the differentiator half)

- board game app discontinued
- board game app server shut down
- will mansions of madness app always work
- board game app support ended

## Monetization-CPC (supporting only — affiliate route)

- mansions of madness board game buy
- xcom the board game price
- board games without companion apps

Notes for the human running the export:
- This is an **affiliate-route** idea (Amazon Associates → base game or a recommended
  non-digital-dependent alternative). Bids are supporting-only per the rubric — a low/blank
  bid does not downgrade Monetization; the grade rides on program-fact verification instead.
- Demand signal cares most about the "Variants" and "Future-proofing" groups — those are the
  two halves of this idea's actual hook (mandatory/optional fact vs. current-support-status +
  fallback). The "Hook-specific" per-game group is inherently long-tail/low-volume; don't be
  surprised if most rows land in the ≤50 bucket or are absent from the export.
