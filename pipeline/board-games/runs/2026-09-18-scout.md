### Pass 4b — deeper re-dig (2026-09-18, after user pushback: "don't believe everything is solved; weigh incumbent-exists less, being new competition is OK")

The first pass killed the four *generic* framings on the first incumbent hit. On re-dig, the pattern is clearer: incumbents cluster on **generic, global, single-answer content** (global "best expansions" listicles, generic "how to teach any board game" method articles, plain per-game rules summaries, global catalog finders). The **per-game × per-user-input compound-tool** layer is thin. Deeper SE + Google probing surfaced live pain that the generic incumbents don't actually resolve:

- **Teach-order / commonly-misplayed rules** — SE `boardgames`: "How can I teach other people game rules?" (q/8891), "Can you play a new player game of Carcassonne w/o farms?" (q/18944 — the farmer rule is the recurring teach-trap), "Are there simplified rules for Race for the Galaxy?" (q/25399). Google: forum threads "Rules Explanation Scripts", "Your teaching script?", "Common mistakes in first plays?", "What are some board game rules that people get wrong". The existing hits are **generic method articles** ("Broad-to-Narrow Method", "Teach Any Board Game in Under 10 Minutes", "13 Easy Steps") and **scattered per-game forum threads / YouTube** — *not* a consolidated per-game database of the specific rules people misplay, verified against rulebook + errata.
- **Expansion worth-it / buy-order** — SE: "in which order should I buy the expansions?" (Alhambra, q/5941). Google: "An attempt at an expansion buying guide" (BGG forum), global listicles ("9 Best Board Game Expansions Ranked", "Top 10 Board Game Expansions"), per-popular-game YouTube ("The Complete 7 Wonders Buyer's Guide"). The named incumbent from pass 4 ("Board Game Expansion Checker: Does It Need the Base Game?") is a **yes/no base-game-required checker only** — it does *not* rank expansions or say which is worth buying first. Global listicles ≠ a systematic per-game interactive ranker.
- **Group-fit before buying** — Facebook/BGG-group thread "Is there a way to filter the games you own for things like player count, suggested age range, complexity/difficulty" (10+ comments, people resorting to custom spreadsheets); Reddit "Is there any website to tell you the best game for X..." (17 posts), "What app randomizes board game selection from a [collection]". The finders (Find Me a Boardgame, Dice Drop) surface games *to buy* from a global catalog; none takes a *specific game the user is already eyeing* + their group and predicts whether it'll land.

Applying the user's steer (incumbent-exists is not an automatic gate-4 kill when the specific hook — per-game, per-user-input, hand-verified — is unserved; a differentiated new entrant is acceptable), **three candidates clear the gates** on a differentiated cut. AIO for each assessed predict-from-form only this run; the manual google.com AIO checkpoint (pass 5) is **still owed** before build.
